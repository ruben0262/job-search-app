# The panel

Everyone in this folder is made up. The names, employers, addresses and results were invented for testing, and the phone numbers and email addresses come from ranges kept for fiction.

The panel gives the CV bench a fixed set of people who are not in IT, with documents of mixed quality, so a prompt can be checked on more than one software engineer's CV. Run it with `--candidates-dir scripts/cvlab/panel --candidates <folder,folder,...>`; each person has two real postings from the local corpus in `scripts/cvlab/jobs/`, the first a close match and the second a stretch.
