# libs/db is imported by nearly every service, so its driver is needed to run the tests. Services still

# Several adapters parse RSS/XML from third-party job boards. Stdlib ElementTree is documented as
# vulnerable to entity-expansion bombs, and the harvester shares a box with Postgres.

# libs/secrets: AES-256-GCM for the KEK/DEK envelope. Every service that can hold a user credential

# imported by the root suite.
cryptography>=44.0
# libs/auth: argon2id with FlowSolutions' production parameters (AUTH_REUSE.md §3). The

# services/api. FastAPI and PyJWT are here because the auth endpoint tests exercise the real

# libs/documents: the upload path extracts text from CVs and references. The tests build real
# .docx and .pdf bytes rather than mocking a parser - a parser mock proves nothing about
# whether a real CV reads.

# change what the gate says about an unchanged look.

python-docx>=1.1
